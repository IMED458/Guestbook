# არქივი — ძველი საჯარო საიტი

აქ დევს იმ მარკეტინგული საიტის კოდი, რომელიც `#/`-ზე იდგა, სანამ პროექტი
სამართავ სისტემად გადაკეთდებოდა. **წაშლილი არ არის** — მარშრუტიდან მოხსნილია,
რომ საჭიროების შემთხვევაში დაბრუნდეს.

| ფაილი | რა იყო |
|---|---|
| `LandingPage.tsx` | მთავარი გვერდი: hero, ფუნქციები, FAQ |
| `MemoryBookShowcase.tsx` | ინტერაქტიული დემო — შრიფტები და თემები |
| `Navbar.tsx` | საჯარო ნავიგაცია |
| `AuthModal.tsx` | ძველი ავტორიზაცია ელფოსტით |
| `GuestBookWizard.tsx` | სტუმრების წიგნის 8-ნაბიჯიანი ოსტატი |

## რატომ არის მოხსნილი

`#/` ახლა პირდაპირ `#/login`-ზე გადაჰყავს. სისტემა შიდა სამუშაო ინსტრუმენტია:
ანგარიშს ადმინისტრაცია ქმნის, სტუმარი კი QR-ით პირდაპირ თავის გვერდზე ხვდება
(`#/g/`, `#/a/`, `#/e/`) — მარკეტინგულ მთავარ გვერდს არავინ გადის.

## როგორ დაბრუნდეს

1. ფაილები დააბრუნე `src/components/`-ში (`landing/`, `layout/`, `auth/`,
   `dashboard/`).
2. `src/App.tsx`-ში `landing` ხედი აღადგინე და `#/`-ის გადამისამართება მოხსენი.
3. `AuthModal` ელფოსტით შესვლას იყენებს — ახალი სისტემა username-ს. თუ ის
   გჭირდება, `signInWithUsername`-ზე გადაიყვანე, თორემ ორი სხვადასხვა გზა
   გაჩნდება ერთსა და იმავე ანგარიშებთან.
4. `GuestBookWizard`-ის ფუნქცია ახლა `#/admin/events`-შია. დაბრუნებისას
   გადაამოწმე, რომ ორივე ერთსა და იმავე მონაცემს არ წერს.

## რა დარჩა მოქმედი

სამართლებრივი გვერდები (`#/legal/*`), ქუქიების ბანერი და საიტის ქვედა ნაწილი
**არ დაარქივებულა** — ისინი კანონით საჭიროა და საჯარო გვერდებზე ისევ ჩანს.
